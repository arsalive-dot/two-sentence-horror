A make.fun entry for the **Two-Sentence Horror** bounty: one horror
story in exactly two sentences, at most 400 characters, written by
`main.py` to `/output/entry.txt`.

The entry: **My smartwatch congratulated me on 10,000 steps before
breakfast. I have not left my bed in three days.**

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic: two runs write byte-identical output.
